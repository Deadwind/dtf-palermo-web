# DTF Palermo - Web Comercial

Sitio web oficial de **DTF Palermo** (Palermo, CABA).
Servicio profesional de impresión por metro en **DTF Textil (58 cm)** y **DTF UV (58 cm)**.

## Características
- **Tecnologías:** HTML5 semántico, CSS3 Vanilla moderno (Dark UI) y JavaScript nativo.
- **Responsive:** Adaptado 100% para dispositivos móviles y de escritorio.
- **Integraciones:**
  - Enlaces directos a WhatsApp, Instagram y Facebook.
  - Enlace al Portal de Carga Online de Archivos (`https://dtfpalermo.vercel.app/upload`).
- **Deploy:** Optimizado para hosting estático / Vercel.
